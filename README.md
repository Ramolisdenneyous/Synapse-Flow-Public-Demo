# Synapse Flow Public Demo

A Docker-hosted portfolio demo of the Synapse Flow visual agent-harness lab.
It defaults to the Four-Agent Blackjack example and includes a built-in Terra
coding assistant for router generation and graph help.

## Safety model

- `OPENAI_API_KEY` exists only in the server environment.
- The shared demo budget is conservatively enforced before every model request.
  Set `OPENAI_DEMO_BUDGET_USD=1.00` for the portfolio deployment.
- The budget state is persisted at `OPENAI_DEMO_DATA_DIR`; mount that directory
  to a Railway Volume at `/app/data` so redeploys do not reset the lock.
- The public demo disables Local RAG, hosted web search, and custom endpoints.
  Wikipedia and Open Library remain available without the OpenAI key.
- Router code is generated by `gpt-5.6-terra`, then validated and executed only
  in the existing capability-free QuickJS sandbox.

## Local run

```bash
copy .env.example .env
npm install
npm run dev
```

Use `npm run build` and `npm test` before deployment.

## Railway deployment

1. Create a new GitHub repository from this folder; never commit `.env`.
2. Connect the repository to a Railway service. Railway detects the included
   `Dockerfile`.
3. Add `OPENAI_API_KEY`, `OPENAI_MODEL=gpt-5.6-luna`,
   `OPENAI_ASSISTANT_MODEL=gpt-5.6-terra`, and `OPENAI_DEMO_BUDGET_USD=1.00`.
4. Add a Railway Volume mounted at `/app/data` and set
   `OPENAI_DEMO_DATA_DIR=/app/data`.
5. Generate a public domain. The service binds to Railway's `PORT` and exposes
   `/api/health` as its health check.

The coding assistant uses the Responses API with `gpt-5.6-terra`. OpenAI lists
Terra as a balanced intelligence/cost model with Responses API and structured
output support.
